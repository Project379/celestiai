Рождени данни — редакция (mobile) · v1

Mock-up only. Reached from Ти; edits the existing chart via PATCH /api/birth-data/{id} (never the create wizard). Every Bulgarian string is PLACEHOLDER copy; the post-save message is an empty slot until you send the approved text.

Reused, nothing invented

  • hero wizard-v4's star — the same warm point, now already placed: the dashed "not yet resolved" ring is solid. R1: one dominant element.
  • fields wizard-v4's lit answer line, once per field (name, date, time, place). Tapping a line activates it (brighter line + soft glow + caret). No cards, no borders, no pills, no chevrons.
  • save dnes-v4's invitation: a lit phrase + breathing ember, not a button. Nothing changed → glow and ember switch OFF and the phrase goes faint (a categorical change, R7), so Save reads as unavailable.
  • options city results, the time-known choice and the approximate range are plain hairline rows (settings-row language) under the active line.
  • type Playfair / EB Garamond only; sizes 12 / 15 / 18 / 20 from the existing scale; zero tracked-caps; no Cinzel.
  • temp warm, restrained — same as the wizard, because this is the same act (telling the app when and where you were born); there is no reading being spoken.

Contract the build must keep

  • PATCH the existing chart id; only send changed fields. No POST. A new chart would change which chart is "active".
  • Save disabled until a field actually differs from the stored value (a no-op edit never bumps birth_data_edited_at).
  • On success: run the shared chart-derived invalidation helper, then show the single post-save message (slot below — copy pending), then return.
  • Unknown time uses the same time-known / approximate-range model as the create flow (birthTimeKnown, approximateTimeRange).

Open design items

  • Entry point: proposed as one plain row on Ти («Рождени данни») in the settings-row language — Ти's own mockup has no such row yet; needs your call on placement.
  • Post-save message: shown in the invitation's place for a moment, then the screen returns. Duration and whether it is tap-to-dismiss are yours to rule; copy is an empty slot.
  • Delete is deliberately absent (cut from Batch 8).

Reduced motion

Star twinkle, ember breathing and the caret blink stop; everything else is already static (no transitions on this screen).

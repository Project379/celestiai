The inverse of Ритъм, now writing not reading

hero No moon-object hero here — the mini-moon + date stays the small cool-toned fitting it already was in lunar-diary-v4 (reading mode). What's new is the writing surface itself: heading + lead + three fields, all typographic, no card wrapping the exercise.

fields Each of the three fields reuses Оракул's ask-line device verbatim (bronze underline + soft glow beneath it + italic placeholder) — the same object family as the moon-detail screen's closing invitation, so entering the diary from there feels continuous rather than like a different app.

register fieldLabels (Настройвам / Подобрявам / Подготвям) sit as small tracked bronze captions above each line — first-person verbs, matching the affirmation/journalPrompt voice already established, not generic "Field 1" labels.

no invitation block No closing CTA on this render — the three lines themselves are the action; saving/submitting is a system affordance (keyboard "done," a header save mark) outside this design pass's scope, same as lunar-diary-v4 left composing open-ended.
